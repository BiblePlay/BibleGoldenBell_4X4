# BibleGoldenBell_4X4

16문제 전용 **도전 바이블 골든벨 4×4** 웹앱입니다.

- 정사각형 4×4 문제판 (1~16)
- 개인 / 2팀 / 3팀 모드
- 맞힌 팀 색으로 칸 배정
- 가로·세로·대각선 BINGO 자동 판정 + 축하 효과
- 각 문제별 일반·초성·빈칸 / OX / 4지선다 / 그림 / 영상 / 숨은그림 설정
- 문제·정답 이미지, 동영상, 오디오(자동/수동) 지원
- PC / Mac 공통 브라우저 사용
- `.bb4` 데이터 파일 하나로 문제와 미디어 이동

## 가장 중요한 사용 방식

집에서 웹앱을 열어 16문제를 만든 뒤 **데이터 저장**을 누르면
`BibleGoldenBell_4X4_YYYY-MM-DD.bb4` 파일이 다운로드됩니다.

행사장 PC/Mac에서는 같은 웹 주소를 열고 **데이터 불러오기**를 눌러
그 `.bb4` 파일 하나를 선택하면 됩니다.

`.bb4`에는 다음이 함께 저장됩니다.

- 16문제 글 / 정답 / 보기 / 힌트 / 문제 유형
- 문제 이미지 / 정답 이미지
- 동영상
- 오디오
- 오디오 자동재생 / 수동재생 설정

> 현재 `.bb4`는 미디어를 원본 바이너리로 묶는 최적화 형식(v2)을 사용해서 Base64 방식보다 불필요한 용량 증가를 줄였습니다. 이전 테스트용 `.bb4`(v1 JSON)도 불러올 수 있습니다.
>
> 영상이 크면 `.bb4` 파일도 그만큼 커집니다. GitHub에는 행사 데이터나 미디어를 올릴 필요가 없습니다.

## GitHub Pages 배포

### 1. 저장소 이름

GitHub 저장소 이름을 정확히 아래와 같이 만드는 것을 권장합니다.

`BibleGoldenBell_4X4`

### 2. 업로드

이 폴더 안의 파일과 폴더를 저장소 최상위에 그대로 올립니다.

`node_modules`는 올리지 않습니다.

### 3. Pages 설정

저장소의 **Settings → Pages → Build and deployment → Source**에서
**GitHub Actions**를 선택합니다.

`main` 브랜치에 올리면 포함된 GitHub Actions가 자동으로 빌드·배포합니다.

### 4. 주소

배포가 끝나면 보통 다음 주소가 됩니다.

`https://사용자이름.github.io/BibleGoldenBell_4X4/`

이 주소를 원하는 홈페이지의 버튼이나 링크에 연결하면 됩니다.

## 운영 권장 브라우저

최신 Chrome / Edge / Whale 사용을 권장합니다.
Safari에서도 기본 기능은 사용할 수 있지만, 대용량 미디어가 포함된 데이터 이동은 Chromium 계열 브라우저가 더 안정적입니다.

## 데이터 위치

웹앱에서 편집 중인 데이터는 현재 브라우저의 저장소에 보관됩니다.
다른 컴퓨터에는 자동으로 전달되지 않습니다.

그래서 행사 전에 반드시 **데이터 저장 → `.bb4` 파일 보관**을 권장합니다.
